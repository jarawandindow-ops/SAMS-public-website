# SAMS public website

Public website preview for **Substance Affected Mob Support**. This is static content only, **not a live client intake service**.

- No forms are operational.
- No personal or confidential client information is stored here.
- Owner logins, CRM and Microsoft Authenticator are part of a separate private application that must undergo security review before production.
- All proposed programs are labelled in development.

The official SAMS logo and illustrated banner will be added to this online preview after the originals are securely transferred to the repository. The current wordmark and illustration are temporary design stand-ins.
